O Restaurante Tupi é um restaurante rústico, localizado no meio da natureza, especializado em pratos regionais como galinha caipira, moquecas, peixes, camarões e queijo de coalho.

O site foi desenvolvido para divulgar o restaurante, seu cardápio e sua localização, melhorando a presença online e facilitando o contato com novos clientes.

## Sobre o Projeto

- Desenvolvido com **Laravel** (PHP Framework).
- Otimizado para **SEO (Search Engine Optimization)**.
- Atualmente aparece na **primeira página do Google** de forma **orgânica** para pesquisas relacionadas.

## Funcionalidades

- Página inicial com apresentação do restaurante.
- Seções de cardápio, localização e contato.
- Otimizações de SEO para melhor posicionamento em motores de busca.
- Layout responsivo para dispositivos móveis.

## Tecnologias Utilizadas

- **Laravel** (Backend e estrutura geral)
- **HTML5**, **CSS3**, **JavaScript** (Frontend)
- **Meta Tags e práticas de SEO** para otimização de buscas.

## Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/tupi_site.git
   ```
2. Instale as dependências:
   ```bash
   composer install
   npm install
   ```
3. Configure o arquivo `.env` com suas informações de ambiente.
4. Rode as migrações (se aplicável) e o servidor local:
   ```bash
   php artisan migrate
   php artisan serve
   ```
